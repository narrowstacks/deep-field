# Website kit

Assets for a Deep Field website, all generated by `Design/Brand/make_media.sh` (see
`Design/Brand/README.md`). Scene images are rendered by the app at their final size, so the
pixel grid is exact; keep them at 1x or scale by whole numbers with nearest-neighbor
(`image-rendering: pixelated`) to keep them crisp.

## Brand

| File | Size | Use |
|---|---|---|
| `logo/wordmark-dark.png` / `.svg` | 900x120 | Wordmark for dark backgrounds. The SVG is a pixel grid and scales freely. |
| `logo/wordmark-light.png` / `.svg` | 900x120 | Wordmark for light backgrounds. |

## Favicons

| File | Use |
|---|---|
| `favicon/favicon.ico` | 16, 32 and 48 px in one file, for `/favicon.ico`. |
| `favicon/favicon-16.png`, `-32.png`, `-48.png` | `<link rel="icon" type="image/png" sizes="...">` |
| `favicon/apple-touch-icon.png` | 180x180 on black (iOS rounds it), `<link rel="apple-touch-icon">`. |
| `favicon/icon-192.png`, `icon-512.png` | Web app manifest icons. |
| `favicon/site.webmanifest` | Manifest referencing the two icons above. |

```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32.png">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta property="og:image" content="https://example.com/og-1200x630.png">
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:image" content="https://example.com/twitter-1200x675.png">
```

## Scene gallery

`gallery/<scene>.png`, 1600x1000 each (cells of 4 px), one per scene: `blackHole`,
`tidalDisruption`, `wormhole`, `binary`, `trinary`, `galaxy`, `pulsar`, `comet`,
`stellarSurface`. `gallery/contact-sheet.png` (2416x1516) shows all nine with their names.

## Loops

`loops/<name>.mp4` (H.264, yuv420p, 12 fps, faststart, no audio) with a matching
`loops/<name>-poster.png` (the first frame) for the `poster` attribute. They loop seamlessly;
use `autoplay muted loop playsinline`. Sizes are 1440x900 except `black-hole` (1920x800) and
`dark-matter` (1936x800, two panels).

| Name | Shows |
|---|---|
| `black-hole` | The black hole's disk turning, 3x speed. |
| `star-meets-black-hole` | The tidal disruption stream, 3x. |
| `pulsar` | One 3-second rotation of the pulsar's beams. |
| `galaxy` | A barred spiral rotating, 24x. |
| `dark-matter` | The same galaxy with and without a dark matter halo, 30x. |
| `coronal-mass-ejection` | Star Close-up event, 14x. |
| `wormhole-emergence` | Something comes out of the wormhole, 9x. |
| `comet-tail-disconnect` | The comet's ion tail breaks off, 12x. |
| `supernova` | A supernova and its light echo in the Binary Stars sky, 10x. |

The MP4s are small (about 9.5 MB together) and committed. For longer or higher quality video,
render more frames with `Design/Brand/loops.py` and attach the result to a release instead of
committing it.

```html
<video autoplay muted loop playsinline poster="loops/black-hole-poster.png">
  <source src="loops/black-hole.mp4" type="video/mp4">
</video>
```
